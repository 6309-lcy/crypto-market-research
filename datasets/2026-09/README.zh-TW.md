## 如何避免再混用資料

後續回測須同時記錄資料集名稱、輸入檔案雜湊、共同幣種、訊號時間與成本設定。下載更新後，只有雜湊一致才屬於完全相同的輸入版本。

K 線標籤是開盤時間；該小時的收盤、高低價及成交量，要等小時結束後才知道。12:00 的決策可以使用已完成的 11:00 K 線，不能讀取 12:00 K 線的最終收盤價。

資金費率為單次結算的原始小數，例如 `0.0001` 是 0.01%，即 1 bp。比較不同週期時才換算，真正計算付款時保留原始費率。這裏的結算費率代表事後結果；它沒有提供結算前整段時間的預估費率快照。

Hyperliquid 的成交 K 線已包含在共同價格資料中。其歷史 oracle／mark 沒有取得的部分維持空值；計算 Hyperliquid 實際資金費金額時，仍需補齊 oracle 或清楚定義估值假設。成交 K 線亦不足以直接確認當時可成交的買賣價差。

成交量保持各 API 原始單位；OKX 合約張數與其他交易所的幣數，須轉換後才能比較。這份資料不預設 USD、USDT、USDC 的價值完全相同。
